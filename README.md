# Smart Waste Guide

AI-Based Waste Segregation Assistant Primary SDG: SDG 12 — Responsible Consumption and Production Secondary SDGs: SDG 11 — Sustainable Cities and Communities, SDG 13 — Climate Action Problem: People often don't know whether an item should go into recyclable, organic, hazardous, or general waste. Incorrect segregation makes recycling difficult and increases landfill waste. AI solution: Build an AI assistant where a user enters the name of a waste item or uploads an image, and the system identifies the waste category and provides disposal/recycling instructions. For example: Input: "Used plastic water bottle" AI: "Recyclable waste. Empty and rinse the bottle before placing it in the recycling collection." Where AI is used You could demonstrate AI through:

Multimodal AI — identify waste from an uploaded image.

Classification — classify the item into waste categories.

Prompt engineering — create prompts that make the AI provide consistent disposal guidance.

RAG — connect the assistant to reliable recycling/waste-management guidelines.

Conversational AI — allow users to ask questions such as "Where should I throw an old battery?"
